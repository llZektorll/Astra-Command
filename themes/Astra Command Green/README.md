# Astral Command

Futuristic Obsidian theme collection with three distinct variants:
- `Astra Command Blue`
- `Astra Command Green`
- `Astra Command Titanium`

| Astra Command Blue | `1.0.0` | clean orbital UI, neon blue/cyan surfaces | Astra Command Blue |
| Astra Command Green | `1.1.0` | bionic tactical interface, sharper geometry | Astra Command Green |
| Astra Command Titanium | `1.2.0` | metallic command deck, steel and gunmetal accents | Astra Command Titanium|

## Installation

### Manual install

1. Open your vault folder.
2. Go to `.obsidian/themes/`.
3. Copy the folder a theam and paste into `.obsidian/themes/`.
4. In Obsidian, go to `Settings -> Appearance -> Themes`.
5. Select the copied theme.
