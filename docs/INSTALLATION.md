# Installation

## Manual Installation

1. Open the target vault folder.
2. Go to `.obsidian/themes/`.
3. Copy one of the theme folders from [`../themes/`](../themes).
4. Open Obsidian.
5. Go to `Settings -> Appearance -> Themes`.
6. Select the installed theme.

## Included Theme Packages

- [`../themes/Astra Command Blue`](../themes/Astra%20Command%20Blue)
